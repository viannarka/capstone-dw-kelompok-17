Tanggung jawab utama saya adalah melakukan profiling dan pembersihan data agar data siap digunakan untuk tahap analisis.

Rencana pekerjaan:

1. Mempelajari struktur dan karakteristik data mentah Kasus 17.
2. Melakukan profiling untuk mengetahui jumlah data, tipe data, dan karakteristik setiap variabel.
3. Mengidentifikasi permasalahan kualitas data, seperti missing values, duplikasi, inkonsistensi, dan anomali.
4. Memeriksa kesesuaian format dan tipe data.
5. Melakukan pembersihan data berdasarkan hasil profiling dan keputusan kelompok.
6. Mendokumentasikan proses pembersihan serta alasan dari setiap keputusan yang diambil.

Selain tugas utama, saya bertanggung jawab membantu proses analisis utama proyek.

Rencana pekerjaan:

3. Membantu memeriksa kesesuaian data hasil pembersihan dengan kebutuhan analisis.
