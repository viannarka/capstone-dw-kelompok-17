## Pekerjaan yang Sudah Dilakukan

- Memeriksa versi Git dan menyiapkan repository lokal.
- Melakukan clone repository kelompok dari GitHub.
- Memeriksa remote repository.
- Membuat dan melakukan push branch kerja pribadi `124450010/kerja`.
- Membuat virtual environment menggunakan Python 3.13 pada macOS.
- Menginstal seluruh library dari `requirements.txt`.
- Mengunduh paket data mentah Kasus 17 – Air Minum dan Sanitasi.
- Memastikan 22 berkas data mentah cocok dengan `MANIFEST.csv` melalui pemeriksaan SHA-256.
- Menjalankan `pipeline.py` untuk memeriksa kondisi awal pipeline. Pipeline berhasil memeriksa manifest, tetapi berhenti pada tahap ekstraksi karena pembaca data masih perlu diimplementasikan.
